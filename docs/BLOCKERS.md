# Bloqueios que dependem da Lilian

1. **Novo projeto Supabase**: a criação tem custo/limite associado à conta. A arquitetura e a migração estão prontas, mas a confirmação precisa vir de você antes de criar um projeto separado.
2. **Repositório remoto GitHub**: a conta conectada permite leitura, mas esta sessão não recebeu permissão para criar repositórios. O repositório Git local está pronto para envio assim que houver autorização de escrita ou um repositório vazio criado.
3. **Netlify**: a publicação requer uma sessão autenticada do Netlify ou token de acesso. O `netlify.toml` já está preparado.
4. **Embeddings reais**: a busca por palavras funciona sem custo adicional. A busca semântica precisa de uma chave de API de embeddings no ambiente do Netlify; ela não será colocada no código.
